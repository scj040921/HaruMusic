# HaruMusic 0.1.12

- Android scroll viewports now reach all four screen edges. Initial safe insets live inside the scrollable content, rather than clipping the entire viewport beneath an opaque toolbar band. The transparent header hides as content scrolls and returns at the top; hidden controls are inert.
- Removed the bottom layout spacer pseudo-element. Only the individual mini player, navigation lens and toolbar buttons paint glass. Reduced white/dark glass fills, highlights and shadows; disabled Android system-bar contrast scrims.
- Navigation supports horizontal pointer/touch dragging. The lens stretches with movement and settles with a velocity-preserving spring; a second gesture can interrupt it. Release selects the nearest tab. Cancellation, vertical gestures, resize and reduced motion are handled separately. Native link dragging and touch capture transfer no longer cancel the interaction.
- Removed Salt UI navigation, settings, renderer, styles and config fields. Existing Salt users migrate to Liquid Glass persistently; lyric preferences and music-source data remain intact. Independent playback transport optimizations and their attribution remain.

Validation: 156 unit tests across 23 suites, node/web type checking, i18n checking, production build and embedded Android API/range/cancellation smoke checks passed. Automated Chromium renderer tests cover five Android routes, transparent surfaces, pointer and real touch-event swipes, interruption, cancellation, resize, reduced motion, download states and mobile lyric controls. A production Electron renderer was launched with an isolated profile to verify migration and the Liquid player, then inspected by screenshot. Physical handset compositor behavior and native system bars still require device acceptance; browser bridge fixtures do not establish those outcomes.
